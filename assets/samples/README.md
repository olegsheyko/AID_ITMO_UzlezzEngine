# Тестовые модели

Модели из [KhronosGroup/glTF-Sample-Assets](https://github.com/KhronosGroup/glTF-Sample-Assets)
для проверки импорта, превью и перетаскивания в сцену. Авторы и лицензии — в `README.md`
и `LICENSE.md` каждой папки.

| Модель | Что проверяет | Лицензия |
|---|---|---|
| Fox | скелет и клипы Survey / Walk / Run, подгонка огромного масштаба | CC0, CC-BY 4.0 |
| DamagedHelmet | статичная модель с PBR-текстурами (jpg) | CC-BY 4.0, CC-BY-NC 4.0 |
| Avocado | крошечная модель — подгонка масштаба вверх | CC0, CC-BY 4.0 |
| Lantern | несколько подмешей и текстуры png | CC0, CC-BY 4.0 |

Лежат вне `assets/models`, потому что тяжёлая загрузка ЛР 1 берёт все картинки оттуда —
иначе изменились бы её замеры.
