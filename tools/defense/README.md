# Запуски для защиты

Двойной щелчок по `00 - МЕНЮ ЗАЩИТЫ.cmd` открывает меню. На этом компьютере пути уже прописаны в `local.json`. Рабочий каталог движка выставляется автоматически: assets найдутся независимо от места запуска ярлыка.

| Файл | Действие |
|---|---|
| 01 - ДВИЖОК - сцена 10000 объектов.cmd | Редактор: 9 900 кубов и 100 анимированных персонажей |
| 02 - ДВИЖОК И TRACY - живой профиль.cmd | Редактор + Tracy с подключением к 127.0.0.1:8091 |
| 03 - ЗАПИСАТЬ TRACY - 30 секунд.cmd | Запись 30 секунд, проверка трассы, открытие её в Tracy. Редактор остаётся открыт |
| 04 - ЗАМЕРЫ - 3 прогона каждого режима.cmd | Пять режимов, три прогона, median/p95/p99; без подключённого Tracy |
| 05 - ЗАПУСТИТЬ ТЕСТЫ.cmd | CTest Release |
| 06 - ОТКРЫТЬ ОТЧЕТ ПО ЛАБЕ.cmd | Сохранённый отчёт с результатами |
| 07 - ОТКРЫТЬ ПОСЛЕДНЮЮ ЗАПИСЬ TRACY.cmd | Последняя записанная трасса |
| 08 - ПРОВЕРИТЬ ГОТОВНОСТЬ К ЗАЩИТЕ.cmd | Проверка путей, версии capture, CMake-флага Tracy и свободного порта |

Перед новым запуском закрой предыдущий GameEngine. Перед замерами закрой также Tracy. Скрипты не закрывают чужие процессы. Live-профилирование и capture нельзя одновременно подключать к одному клиенту; для нового режима закрой предыдущие окна.

В Tracy раскрой главный поток и ищи зоны `Scene visibility and submission`, `Visible set and sorted packet`, `Submission packet`, `Animation update`, `Animation poses`. На таймлайне выбирай кадры после загрузки сцены. Сравнивай выключенные и включённые culling/sorting. Зоны CPU не являются измерениями GPU. Подключённый профилировщик добавляет нагрузку, поэтому итоговые CSV снимаются отдельным пунктом меню.

В редакторе открой Scene и Renderer Info. ПКМ + WASD, Q/E: камера. Frustum culling / Sort submission: сравнение режимов. Move 100 objects: дополнительное движение персонажей. Add 100 / Delete 100: проверка изменения реестра.

Новые результаты сохраняются в `output/<дата-время>-<режим>` без перезаписи предыдущих. Трассы, логи и локальные пути исключены из Git. Для другого компьютера скопируй `local.example.json` в `local.json` и укажи свои пути. Нужны готовая Release-сборка с ENGINE_ENABLE_TRACY=ON, Tracy 0.14.1 и Python для полного бенчмарка. Ничего автоматически не скачивается.

Запись произвольной длительности (1–300 секунд):

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/defense/Launch.ps1 -Mode Capture -Seconds 60
```

`ExecutionPolicy Bypass` действует только на запускаемый процесс PowerShell. Системная политика не меняется. Сборка и публикация кода этими скриптами не выполняются.

Все относительные пути в параметрах и local.json отсчитываются от корня репозитория, независимо от текущего каталога терминала. По умолчанию: build/windows/Release/GameEngine.exe и build/tracy-tools. Абсолютные пути тоже поддерживаются. CTest ищется в PATH, затем в CMakeCache.txt выбранной сборки.
